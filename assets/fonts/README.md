# Fontes de terceiros

- Google Sans, Google Sans Display, Google Sans Text: SIL Open Font License 1.1; aviso de copyright do projeto Google Sans em `OFL-GoogleSans.txt`.
- Google Sans Flex: SIL Open Font License 1.1; aviso de copyright do projeto Google Sans Flex em `OFL-GoogleSans.txt`.
- Roboto Mono: SIL Open Font License 1.1, `OFL-RobotoMono.txt`.

Os avisos Google Sans foram reunidos porque o texto da licença é o mesmo; ambos os avisos de copyright upstream estão preservados. As licenças-fonte vêm de `google/fonts/ofl/googlesans/OFL.txt`, `google/fonts/ofl/googlesansflex/OFL.txt` e `google/fonts/ofl/robotomono/OFL.txt`.

Os arquivos-fonte mínimos usados para reproduzir `frontend/src/styles/fonts.css` ficam em `google-sans/source/`; a aplicação serve os subconjuntos em `frontend/public/fonts/`. Licenças verificadas nos repositórios oficiais `googlefonts/googlesans` / `googlefonts/googlesans-flex` e `googlefonts/robotomono`. As páginas e bundles de terceiros anteriormente usados como referência visual não fazem parte da distribuição atual.
